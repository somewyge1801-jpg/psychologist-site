# Сайт частного психолога

Демонстрационная версия одностраничного сайта частного психолога: познакомиться со специалистом, понять формат и условия, связаться для записи. Стек — React + TypeScript + Vite, обычный CSS с токенами, минимум зависимостей.

## Запуск

Требуется Node.js 18+.

```bash
npm install        # установить зависимости
npm run dev        # режим разработки → http://localhost:5173/
npm run build      # продакшен-сборка в папку dist/
npm run preview    # локальный предпросмотр собранной версии
```

## Структура проекта

```
src/
  data/site.ts        — единый источник всего контента сайта
  styles/tokens.css   — дизайн-токены (цвета, типографика, сетка, отступы, радиусы)
  App.tsx             — компоненты страницы
  App.css             — стили компонентов
  main.tsx            — точка входа
public/favicon.svg    — фавикон
dist/                 — результат сборки
```

## Как менять контент

Всё видимое на сайте управляется из одного файла — `src/data/site.ts`.
Чтобы заменить имя, тексты, список запросов, условия или FAQ, правьте данные в этом файле. Дизайн менять не нужно.

Временные данные и то, что необходимо заменить, перечислены в **content-checklist.md**.

## Демонстрационный режим

Сайт работает без реальных контактов и формы: кнопка связи открывает аккуратное пояснение, что контакт ещё не настроен. Это осознанный демонстрационный режим — блокер публикации (см. ниже).

## Блокеры публикации

1. Нет реальных контактов и формы — демо-окно нужно заменить на реальный канал (мессенджер/почта).
2. Нет подтверждённой квалификации — блок «Обо мне» использует нейтральные формулировки без дипломов.
3. Нет юридических документов (политика конфиденциальности, оговорка об ответственности) — нужно составить после определения владельца и форм сбора данных, по актуальным источникам (РФ: 152-ФЗ).
4. Демонстрационные условия (длительность, цена, перенос) — заменить на реальные.

Полный список — в **content-checklist.md**.

## Технические примечания

- `vite` использует `esbuild`; `npm audit` сообщает об уязвимостях dev-сервера esbuild ≤0.24.2. Исправление требует breaking-change-мажора Vite (8.x). Для собранного статического сайта (dist/) dev-сервер не используется, поэтому на прод-артефакт это не влияет; при желании можно перейти на Vite 8.

## Пользовательские сценарии

- Понимание процесса и условий — первый экран, блоки «С какими вопросами», «Как проходит работа», «Формат и условия».
- Знакомство со специалистом — блок «Обо мне» с принципами и проф. границами.
- Связь для записи — секция «Связаться» + демо-модальное окно (до настройки реального контакта).
- FAQ — блок «Частые вопросы» (аккордеон, 6 вопросов).
