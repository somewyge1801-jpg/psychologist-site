# Дизайн-направление «Ясная консультация»

Дата: 2026-11-18.

## Direction (по методу Unslop)

- **Продукт.** Сайт частного психолога для взрослой русскоязычной аудитории: познакомиться со специалистом, понять формат, условия и связаться для записи на индивидуальную онлайн-консультацию.
- **Характер.** Собранный, спокойный, уважительный, с лёгкой теплотой.
- **Мир.** Настоящий разговор, происходящий в тихом месте: бумага, записи клиента, дневной свет, чашка чая. Не клиника, не приложение, не курс.
- **Моменты цвета и материала.** Нумерованные шаги «Как проходит работа» — центральный мотив, несущий структуру; тёплый терракотовый акцент на одном ключевом действии (кнопка записи) и на важных элементах. Предметный визуал спокойный, без лица.
- **Сигнатура (узнаваемая деталь).** Нумерованные шаги процесса (01, 02, 03…) — единый мотив, встречается в блоке «Как проходит работа», «Формат и условия» и на кнопке процесса. Только здесь, больше нигде.

## Токены

CSS-переменные (src/styles/tokens.css).

### Цвета (тёплый нейтральный рамп + один акцент)
- `--bg` — #F7F4F0 (тёплый белый бумажный фон)
- `--surface` — #FFFFFF (поверхности карточек)
- `--surface-muted` — #EFEAE3 (лёгкие тонированные поверхности)
- `--border` — серая линия 6–10% от `--ink`
- `--ink` (основной текст) — #2B2926 (тёплый графит, контраст на фоне > 9:1)
- `--ink-secondary` — #5A5650
- `--ink-muted` — #7C7770
- `--accent` — #9C4A2F (приглушённый терракот, контраст белого текста на нём > 4.5:1)
- `--accent-ink` — тёмный оттенок терракота для текста на светлом фоне
- Ошибка/успех — тонированные семантические цвета (SR-only, для будущих состояний)

Контраст основной пары ink/bg рассчитывается: #2B2926 на #F7F4F0 — значение в диапазоне 12–14:1 (превышает 4.5:1 для обычного текста). Точный расчёт — тестовые страницы в проверке.

### Типографика
- Headings: **PT Serif** (кириллица хорошая, деликатный характер), 400.
- Body/UI: **PT Sans** (кириллица хорошая), 400/500.
- Размеры: основной текст 17px, высота строки 1.65; заголовки по шкале. Sentence case, без капса-лейблов с широким трекингом.
- Негативный трекинг только на крупных заголовках (display), на мелком тексте не использовать.
- Числа — tabular-nums.

### Сетка и отступы
- Шкала кратна 4px; внутренние расстояния карточек 20–24, поля страницы 24–32.
- Контентная колонка ~ 62–70 символов.
- Макс. ширина контейнера 1120px, колонка текста ~680px.
- Радиусы: контролы 10, карточки 14, панели 16. Вложенный радиус = внешний минус отступ.
- Тень — мягкая нейтральная, мелкая; без цветных свечений.

### Интерактивные состояния
- Hover: быстрая смена цвета поверхности (transition-colors), без scale.
- Нажатие: лёгкое сжатие (transform, ~0.98).
- Focus: видимое focus-кольцо в палитре.
- Duration: 120ms для feedback, 220ms для появления.

### Движение
- Не более одной быстрой анимации входа. `prefers-reduced-motion: reduce` отключает анимации.
- Нет бесконечных пульсаций, параллакса, свободно плавающих объектов.

## Чего избегаем
Любые глянцевые блобы, градиенты на поверхностях, неоновые свечения, стеклянные карточки, эмодзи-иконки, карусели, одинаковые карточки во всех секциях, абстрактные 3D-мозги.
